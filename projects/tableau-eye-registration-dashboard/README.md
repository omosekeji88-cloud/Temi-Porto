# Tableau Eye Registration Dashboard

This Tableau workbook presents a dashboard built around my final-year dissertation work on 3D eye registration.

The dashboard explores whether 3D registration can reliably align healthy and diseased eyes by bringing together outputs from the reconstruction and registration pipeline, including:

- ICP alignment results
- CPD matching outputs
- deformation metrics
- PCA-derived variation
- lesion-related analysis
- cohort-level comparisons

## Portfolio Value

This project demonstrates how technical biomedical-engineering outputs can be translated into an interactive dashboard for clearer communication. It shows experience with Tableau, dashboard design, visual analytics, data storytelling and the presentation of complex 3D modelling results to a non-specialist audience.
