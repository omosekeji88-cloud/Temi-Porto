Analyst Summary

The dataset contains 284,807 transactions but only 492 confirmed fraud cases, producing a fraud rate of 0.173%. This makes the project useful for showing BI work on imbalanced data, where percentage rates, segmented views and high-risk transaction monitoring are more informative than raw counts alone.
